# Career Intelligence — personal project

A small, static information page for the Career Intelligence personal job-search project.

## Project status

Career Intelligence is planned as a private job-discovery and career-management workspace inside Second Brain. Its product specification and initial screen concepts are documented, but source validation is still underway. The actual application, automated ingestion and production deployment have not been implemented.

This site intentionally describes planned capabilities as planned. It is not a live job board, recruitment agency or application-submission service.

## Deploy to Vercel

1. Open **Add New → Project** in Vercel and import this repository.
2. Deploy it as a static site. No framework, build command or environment variables are required.
3. Leave the root directory as `.` (the repository root).
4. After deployment, open the generated `*.vercel.app` URL and confirm that the page is publicly accessible.
5. Only then use the live URL in the Adzuna Organisation/Group website field.

## Privacy

The page has no login, forms, analytics scripts, cookies or external JavaScript dependencies. Do not add API credentials, OAuth tokens, resumes or personal application data to this public repository.
